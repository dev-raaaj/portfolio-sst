# Prithvi Raj Singh — Developer Portfolio

A responsive, minimalist developer portfolio designed with a focus on system architecture, typography, and clean micro-interactions. Built without third-party UI libraries or build frameworks.

---

## ✦ Core Features

- **Semantic Document Architecture:** Built using HTML5 structural landmarks (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`).
- **Warm Minimalist Design System:** Custom theme utilizing cream, muted peach, and slate-blue CSS variables for high-contrast accessibility.
- **Responsive Layout Engine:** Responsive design powered by CSS Grid and Flexbox with breakpoints at `768px` and `480px`.
- **Hardware-Accelerated Micro-Interactions:** Pure CSS transitions, transforms, and `@keyframes` (pulse indicators, dynamic scanline hover states).
- **Interactive Forms & Navigation:** Sticky navigation bar (`position: sticky`, `backdrop-filter`) and an accessible feedback contact form.
